Machine Learning For Predicting Future Stock
Prices With Financial Data And Visual Features

Abstract—This thesis explores stock price prediction for financial data and visual features particularly images of cars. Using regression methods and computer vision techniques we analyze quarterly reports, historical prices and car images to identify patterns influencing stock prices of car manufacturers. Comparative evaluation highlights effective prediction methods advancing predictive modeling in finance. Our findings provide valuable insights into stock market dynamics aiding decision making for investors and analysts by uncovering the relationship between non-textual data and stock trends. Our results demonstrate that the Histogram of oriented gradients (HOG) model outperformed other methods for feature extraction while XGBoost Regression proved to be the most effective method for stock price prediction as regression and Support vector machine (SVM) as classification. Lastly, we found that predicting stock prices using only the quarter report financial summary shows better results compared to integrating it with visual features of car images. Index Terms—Machine Learning, Stock Price Prediction, Financial Data, Visual Features, Computer Vision, Regression Methods, Deep Learning
